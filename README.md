# portfolio-site

Personal portfolio for Isaac Njoroge, a full stack software developer: https://isaacnjoroge.com

Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

## Run locally

```
python -m http.server 8080
```

Then open http://localhost:8080.

## Structure

- `index.html`: single-page portfolio (hero, about, experience, projects, contact)
- `case-studies/`: longer write-ups, linked from project cards
- `css/`: `styles.css` (layout and theme tokens) and `animations.css`
- `js/`: scroll and nav behaviour, typing line, star background, contact form
- `files/`: downloadable resume

## Built with

HTML5, CSS3, vanilla JavaScript, Font Awesome, Devicons, Web3Forms for the contact form.
