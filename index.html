About Me

A full stack developer currently at SilverBirch Studios, where I build and maintain production systems for enterprise clients across healthcare, education and live events. I own features end to end, from the Spring Boot endpoint and database migration to the React and Next.js screen that uses it. I care about clean architecture, secure API design, and code that holds up under pressure.

My core is Java and Spring Boot, with PHP as well: microservices, RESTful APIs, authentication and authorization, and databases with PostgreSQL, MySQL and Redis. On the frontend I work with React, Next.js and TypeScript. I test what I ship, review pull requests carefully, and use AI tools every day while checking their output.

I'm fully committed to lifelong learning and genuinely excited by the pace at which this industry moves. Outside of code I enjoy reading web comics, hitting the gym, and gaming.

LLM Agent · Rule-Based Trading
In Progress Personal Project

Tradie-Lite

Tradie-Lite is an LLM-driven workflow for EUR/USD M5 scalping. A five-step pre-trade gate checks the setup, indicators, the economic calendar and risk before any order is considered, using TradingView and MetaTrader 5 through MCP servers.

  • • Rule-based strategy with a Pine Script indicator; the LLM validates each setup instead of predicting prices
  • • Local economic-calendar check to avoid trading into high-impact news
  • • Post-mortems on skipped setups drive rule changes, for example moving an RSI filter from slope to zone
